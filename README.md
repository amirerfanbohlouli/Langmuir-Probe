📁 About This Repository
In this repository, I publish all the simulations, embedded codes, design files, and documentation related to my Master's thesis project:

"Design and Construction of a Power Supply and Data Acquisition System for a Langmuir Probe"

Langmuir probes are one of the most fundamental and critical diagnostic tools for measuring plasma parameters (such as electron temperature, density, and plasma potential). A reliable power supply and a high-speed data acquisition (DAQ) system are essential for extracting accurate data from these probes, especially in pulsed or steady-state fusion plasma devices.

Here, you will find:

Circuit schematics & PCB designs for the probe power supply.

Firmware / Software codes (e.g., Arduino, STM32, or Python-based DAQ scripts) for controlling the sweep voltage and acquiring current-voltage (I-V) characteristics.

Simulation models (e.g., SPICE, MATLAB, or Python) used to design the power supply and validate the probe's theoretical behavior.

Data analysis scripts for processing raw I-V traces to extract plasma parameters.

Experimental data (if publicly available) and calibration files.

🛠️ Technologies & Tools Used
Hardware Design: Altium Designer / KiCad, LTSpice

Microcontrollers / DAQ: STM32, Arduino, or National Instruments (NI) DAQ

Programming Languages: Python, C/C++

Data Analysis & Simulation: MATLAB, Python (NumPy, SciPy, Matplotlib)

Fusion/Plasma Physics: Langmuir probe theory, plasma sheaths, I-V characteristic interpretation
